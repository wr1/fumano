**DocKB** is a documentation system that gives you clean, user-facing docs in `docs/` powered by [Fumadocs](https://fumadocs.dev), with an optional `kb/` layer for rich collaboration.

## Two Modes

- **Plain mode** — No `kb/` folder. Clean public documentation only. No commenting UI.
- **Rich mode** — `kb/` folder present. Commenting UI is enabled + access to internal developer knowledge in `kb/dev/`.

The switch is automatic: just the presence of the `kb/` directory at the project root.

## Core Ideas

- Main documentation lives only in `docs/`.
- `kb/comments/` stores every comment as a flat, timestamped JSON file.
- `kb/dev/` holds internal notes (never synced into public docs).
- No build step or sync between layers.
- Designed to be extremely usable by agents (direct file reads/writes).
